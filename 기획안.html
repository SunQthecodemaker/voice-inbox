2. 확정된 결정

항목결정이유
저장소 정본 옵시디언 vault 단독 검색·재발견 + 아이디어 발전 페인 둘 다 옵시디언 강점에 매핑됨. Notion 평면 DB 의 한계가 페인 자체
vault 위치 \\Sunq\sunq\vault\inbox\ 이미 운영 중인 vault. Synology Drive 동기화로 멀티 PC·모바일 sync 완비
분류 모델 영역 1축 고정 + 자유 태그 영역 3개(병원·개인업무·개인생활)는 MOC·회고 뷰 분리에 진짜 필요한 축. 항목·유형은 메모 내용 따라 자유롭게 자라남
vault 쓰기 통로 NAS WebDAV (Edge Function → vault) DB 는 NAS 이용 OK 라는 사용자 결정. GitHub 경유 제외. 인증서·포트포워딩 이미 준비됨 (sunq818.synology.me)
GitHub 경유 ✗ 안 함 사용자 명시 거부
Notion 처리 즉시 폐기 "역할이 단지 백업이라면 굳이 필요 없음" — 사용자 결정 (2026-05-18). 기존 메모는 필요 시 1회성 export 로 vault 이관
